# IVC Website Content Inventory

## Purpose

This directory contains the Phase 1 research inventory for the Immunization
Vocabularies Collaboration (IVC) website. It records potentially useful source
material, possible website uses, and questions that must be resolved before
publication.

This is not approved public copy. A `Keep` or `Revise` recommendation means the
source is worth carrying forward for editorial review, not that every claim is
current or approved.

## Current scope

Initial review completed on 2026-10-07 covered:

- This repository, its prototype homepage, and its content plan
- Public pages linked from the current IVC DokuWiki site map
- The DokuWiki meeting and presentation indexes
- The Bordeaux 2025 summary and an external event recap
- Public NUVA overview, distribution, release, and implementation links
- Nathan's first-party direction supplied on 2026-10-07

The review is organized around three priorities:

1. Explain why IVC exists, what it does and does not do, the vaccine-vocabulary
   problem, and NUVA; provide space for reactions and updates.
2. Preserve access to past meetings, presentations, notes, and the Bordeaux
   meeting record.
3. Link to NUVA materials now while leaving room for a separate NUVA/code-system
   management project to integrate later.

## Initial findings

- The project was deliberately rebranded from **International Vaccine Codes
  Initiative** to **Immunization Vocabularies Collaboration** to describe the
  work more clearly and avoid the loaded meanings of “International.” The old
  name should remain only where historical context or a source title requires
  it.
- The strongest starting material for IVC's purpose and boundaries is the
  DokuWiki home page, reinforced by early meeting presentations. It still needs
  scope and currency review before reuse.
- The meeting and presentation indexes contain a substantial archive from 2023
  onward. Files need privacy, accessibility, ownership, and duplication review.
- The Bordeaux 2025 page could support an event overview, session summaries,
  and original-material links after owner review.
- NUVA has useful public descriptions and technical resources, but sources are
  inconsistent about ownership, stewardship, licensing, IVC's role, SNOMED CT,
  and the update process.
- The prototype is a content hypothesis, not an authoritative source. Its dated
  update entries are examples rather than real publications.
- No source reviewed so far defines the editorial process or publishing model
  for the requested blog/update space.
- The local working collection confirms a useful scope boundary and contains
  strong raw material, but it must not be bulk-published: it mixes public
  candidates with private contacts, attendance, funding, strategy, and candid
  working notes.

## Inventory conventions

Status values are **Reviewed**, **Located**, **Requested**, and **Verify**.
Recommended actions are **Keep**, **Revise**, **Combine**, **Archive**, **Omit**,
and **Verify before deciding**. Add one row for each independently useful source
or coherent collection, include an access date for web material, and put open
work in the backlog. Preserve dates and historical context for meeting content.
