# Technical resources and shared knowledge

IVC collects and develops practical information for people who create,
maintain, interpret, and implement vaccine code sets. This focused collection
will grow as technical work is reviewed and maintained.

## NUVA

Learn how the Unified Nomenclature of Vaccines represents administered
vaccines, uses valences to describe their function, and supports relationships
with existing vaccine codifications. Access current NUVA information,
distribution files, and companion files.

[Explore NUVA](nuva.md)

## Articles

Articles offer concise context about principles that guide IVC's work. They are
dated perspectives, not substitutes for maintained technical documentation or
binding IVC positions.

### Rich information is part of interoperability

Moving a vaccine code between systems is useful only when its meaning can
travel with it.

[Read the article](articles/rich-information-is-part-of-interoperability.md)

## Meeting presentations

Past IVC meetings preserve practical technical discussions and presentations
in their historical context. InteropHub provides the chronological meeting
archive, native agendas, and selected presentation downloads.

[Browse IVC meetings and presentations](https://informatics.immregistries.org/hub/es/meeting-series?seriesId=1)

## More resources over time

IVC is developing additional tools and knowledge resources around vaccine-code
documentation, NUVA alignment, and related measures. We will add links when
those resources are ready, reviewed, and maintained.
