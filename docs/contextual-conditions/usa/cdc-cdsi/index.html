About this code system

The U.S. Centers for Disease Control and Prevention (CDC) Clinical Decision Support for Immunization (CDSi) project publishes Supporting Data that includes a list of coded observations. These codes are referenced as indications and contraindications in the CDSi antigen supporting data and are widely used by U.S. immunization forecasting engines.

Contextual conditions defined by the CDC CDSi project and published by CDC as the Coded Observations in the CDSi Supporting Data. Each code represents an operational assertion that a condition applies to a patient for immunization clinical decision support. These are not diagnoses or clinical findings. This resource is an IVC proof-of-concept representation. It is not a CDC publication and is not endorsed by CDC.

Operational assertions, not diagnoses. Each code asserts that a condition applies to a patient for immunization decision support. The sender decides whether the condition applies, and the receiving IIS or CDS engine uses the assertion. These codes are not problem-list entries, clinical findings or inference rules.

  • The CDSi source has no expected answer type. IVC added expectedValueType from the IVC-supplied workbook (Proposed Values.xlsx). Code 280 is newer than that workbook, so IVC assigned it 'boolean' as a default that has not been reviewed.
  • Related SNOMED CT, CVX and PHIN VS codes are shown as concept properties because that is how CDSi supplies them. CDSi says these are representative of related concepts, not exhaustive and not equivalent. A ConceptMap may be the better long-term representation.
  • The PHIN VS related codes use the system URI urn:oid:2.16.840.1.114222.4.5.274, which IVC has not yet confirmed.
  • Code 231: CDC's XML has a literal '?' in its clarifying text where the official spreadsheet has '≤' ('heart disease at age ≤50 years'). The XML value is preserved and the difference is flagged. This should be reported to CDSi.
  • Two distinct codes (138 and 140) share the display 'IGIV - Immune thrombocytopenic purpura treatment'. Both are preserved as published by CDSi.
