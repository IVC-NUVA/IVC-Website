About this code system

Syadem is a France-based organization that develops MesVaccins and its immunization decision-support expert system. Its contextual conditions are used to tailor vaccination recommendations. This is not an official French-government terminology, and its placement under the 'fra' namespace does not imply endorsement by the French government.

Contextual conditions defined by Syadem for use in immunization clinical decision support. Each code represents an operational assertion that a condition applies to a patient. These are not diagnoses or clinical findings. Labels are supplied in French and English. This resource is an IVC proof-of-concept representation published with Syadem's permission.

Operational assertions, not diagnoses. Each code asserts that a condition applies to a patient for immunization decision support. The sender decides whether the condition applies, and the receiving IIS or CDS engine uses the assertion. These codes are not problem-list entries, clinical findings or inference rules.
