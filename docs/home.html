Why this work matters

Vocabulary is essential infrastructure

Vaccine vocabularies allow immunization systems to record which vaccines were given and preserve that meaning as records move between systems, organizations, and countries.

3

Build useful resources

NUVA, alignment work, articles, and meeting presentations turn discussion into knowledge that others can use.

A shared technical foundation

NUVA is at the center of IVC's technical work

NUVA—the Unified Nomenclature of Vaccines—is an open, shared ontology for representing administered vaccines and their valences consistently across existing vaccine code systems and over time.

It does not replace national, regulatory, product, billing, or clinical code systems. It provides a shared model that can help people interpret and relate them.
