## Photographs

The `photos` tree contains 82 files representing 60 unique images:

- 22 files are redundant copies.
- 21 hash groups contain duplication.
- `IMG_2308.JPG` appears three times: in the main folder and in both the
  `Myriam` and `Shannon` subfolders.
- The remaining duplicated images are copies between the main folder and one
  named contributor subfolder.
- `Pictures from Meeting.pptx` is a 12-slide curated derivative, not an
  independent photo source.
- `20250514_110331.jpg` has a later filename date and should not automatically
  be assumed to depict the 9 May summit without visual/owner confirmation.

Recommended process before website use:

1. Work from the 60 unique originals, not contributor-folder duplicates.
2. Ask the organizer to identify the event, people, photographer, and intended
   public use for shortlisted images.
3. Confirm the consent/rights basis and avoid exposing badge or screen details.
4. Select a small representative set rather than publishing a gallery dump.
5. Write factual captions and useful alt text.
6. Preserve photographer credit where known.

## Version and retention rules established by this review

- Retain a final/delivered file plus materially distinct drafts that explain
  decisions; mark routine intermediate drafts as superseded.
- Treat DOCX/PPTX and PDF as source/export pairs only after content comparison;
  matching basenames alone are insufficient.
- Keep acquisition ZIP files internal when their contents have been extracted
  and inventoried.
- Never use file modification time as the event date without corroboration.
- Preserve historical organization names inside original artifacts.
- Do not publish raw participant data, contact material, or confidential decks.
